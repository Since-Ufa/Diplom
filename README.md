# Дипломный проект: структура репозитория

## Общий обзор

Этот репозиторий содержит материалы выпускной квалификационной работы по теме "Электронно-возбужденные состояния в кластерах меди, защищенных тиолятами". Основная часть проекта представляет собой текстовую и презентационную документацию, подготовленную в LaTeX, а также набор графических файлов, используемых в работе.

В текущей версии проекта в дереве репозитория отсутствуют самостоятельные Python- или bash-скрипты, файлы вводов/выходов ORCA или GROMACS, а также координатные/геометрические файлы типа .xyz, .pdb, .gro, .gjf и т. п. Основной материал хранится в виде исходников LaTeX, собранных PDF, рисунков и служебных документов.

## Основные каталоги проекта

- `paper/` — основной текст дипломной работы и связанные рисунки/стили.
- `presentation/` — презентация для защиты с дополнительными заметками.
- Корневые документы — итоговые служебные материалы (отзывы, ответы на вопросы, расписание).

---

## Корневая папка

В корне репозитория находятся общие служебные и административные документы проекта, а также ссылки на основную работу.

### Содержимое корневой папки

- `README.md` — общая информация о проекте и его структуре.
- `paper/` — папка с текстом диплома.
- `presentation/` — папка с презентацией.
- `Ответы_на_вопросы.docx` — ответы на вопросы, подготовленные для защиты.
- `Отзыв_научрук_Буглак.pdf` — отзыв научного руководителя.
- `Отзыв_рецензент_Ксенофонтов.docx` — отзыв рецензента.
- `Расписание_выступлений.docx` — расписание выступлений/защитной части.

> В корне репозитория нет отдельного каталога с вычислениями, сценариями или входными файлами квантово-химических расчётов. Все существенные материалы оформлены в виде итоговых текстов и графики.

---

## `paper/`

Каталог `paper/` содержит основной текст дипломной квалификационной работы: LaTeX-исходники, библиографию, стили, компилированный PDF и изображения, вставленные в текст.

### Основные файлы `paper/`

- `main.tex` — главный LaTeX-файл диплома.
- `main.pdf` — собранная версия текста работы в PDF.
- `links.bib` — библиографическая база данных.
- `templates.tex` — вспомогательные LaTeX-шаблоны/макросы.
- `gerb.png` — изображение герба/логотипа.
- `gost-numeric.bbx` — стиль библиографии для ГОСТа.
- `slashbox.sty`, `slashbox.tex`, `spbu-ff-3kurs.sty`, `spbu-ff-3kurs_original.sty` — стили и вспомогательные модули форматирования.
- `README.md` — краткая заметка о проекте/работе.
- `main.aux`, `main.bbl`, `main.bcf`, `main.blg`, `main.log`, `main.out`, `main.run.xml`, `main.synctex.gz`, `main.toc` — служебные артефакты, создаваемые LaTeX-компиляцией.

### `paper/pictures/`

Папка `paper/pictures/` хранит графические файлы, использованные в дипломе. По смыслу это визуализация теоретических моделей, спектров, структур и результатов расчётов.

#### `paper/pictures/`

- `metal_NCs.png` — иллюстрация нанокластеров и энергетических уровней.
- `stability.png` — визуализация стабильности или сравнения структур.
- `abs_emm.png` — спектры поглощения/люминесценции.
- `cu_mass_spec.png` — масс-спектрометрические данные.
- `opt_Cys_vac.jpg`, `opt_Cys_wat.jpg` — оптимизированные структуры для цистеина.
- `opt_SCH3_vac.jpg`, `opt_SCH3_wat.jpg` — оптимизированные структуры для метилтиогруппы.
- `Absorption-D3.opju` — исходный проект в Open/LibreOffice Draw/Illustrator-стиле для графики.

#### `paper/pictures/orbitals/`

Папка с изображениями орбитальных рисунков и визуализации электронных состояний.

- `Cu2L2_1.jpg`, `Cu2L2_2.jpg`, `Cu2L2_3.jpg` — изображения орбитальных состояний/электронной плотности для кластеров.

#### `paper/pictures/spectra/`

Папка со спектральными графиками и их векторизованными версиями. Это основной набор данных, отражающих сравнение теоретических методов и экспериментальных результатов.

- `CAM-B3Lyp_vacuum.eps` / `.pdf` — спектры, полученные методом CAM-B3LYP.
- `M06-2X_vacuum.eps` / `.pdf` — спектры для M06-2X.
- `COMP_Cu_vacuum.eps` / `.pdf`, `COMP_Cu2_vacuum.*`, `COMP_Cu3_vacuum.*`, `COMP_Cu4_vacuum.*`, `COMP_Cu5_vacuum.*` — сравнительные спектры для разных кластеров.
- `Cu_vacuum.*`, `Cu2_vacuum.*`, `Cu3_vacuum.*`, `Cu4_vacuum.*`, `Cu5_vacuum.*` — отдельные спектры для кластеров.
- `Cys_CAM-B3Lyp_vacuum.*`, `Cys_M06-2X_vacuum.*` — спектры для комплексов с цистеином.

> В этой папке хранятся геометрически и спектрально значимые изображения, но не файлы входов/выходов квантовых расчётов. Это графическая репрезентация результатов, а не исходный расчётный материал.

## `presentation/`

Каталог `presentation/` содержит материалы для устного доклада и защиты диплома. Основной формат — презентация на LaTeX/Beamer.

### Основные файлы `presentation/`

- `main.tex` — главный файл презентации.
- `main.pdf` — собранная презентация в PDF.
- `main.aux`, `main.log`, `main.nav`, `main.out`, `main.snm`, `main.synctex.gz`, `main.toc` — служебные файлы компиляции.
- `Logo_new.jpg` — логотип/элемент оформления титульного слайда.
- `ЗАМЕТКИ.txt` — подробные заметки по слайдам.
- `ЗАМЕТКИ_КРАТКО.txt` — краткая версия заметок по содержанию презентации.

### `presentation/pictures/`

Папка с рисунками, которые используются в слайдах. По назначению она повторяет часть графического банка диплома, но адаптирована к презентационному формату.

#### `presentation/pictures/`

- `Cu3L2.png` — иллюстрация трёхатомного кластера меди.
- `metal_NCs.png`, `stability.png`, `abs_emm.png`, `cu_mass_spec.png` — общие иллюстрации и экспериментальные данные.
- `opt_Cys_vac.jpg`, `opt_SCH3_vac.jpg` — оптимизированные структуры.

#### `presentation/pictures/orbitals/`

- `Cu2L2_1.jpg`, `Cu2L2_2.jpg`, `Cu2L2_3.jpg` — изображения орбитальных состояний/электронной структуры.

#### `presentation/pictures/spectra/`

Расположены спектральные рисунки для презентации и цифровых сравнений:

- `CAM-B3Lyp_vacuum-eps-converted-to.pdf`
- `Cys_CAM-B3Lyp_vacuum-eps-converted-to.pdf`
- `Cys_M06-2X_vacuum-eps-converted-to.pdf`
- `M06-2X_fix_vacuum-eps-converted-to.pdf`
- `M06-2X_vacuum-eps-converted-to.pdf`
- `exci_wB97X-D3_vacuum-eps-converted-to.pdf`
- `Cu_vacuum-eps-converted-to.pdf`, `Cu2_vacuum-eps-converted-to.pdf`, `Cu3_vacuum-eps-converted-to.pdf`, `Cu4_vacuum-eps-converted-to.pdf`, `Cu5_vacuum-eps-converted-to.pdf`

Эти файлы служат наглядной визуализацией сравнительного анализа методов и подтверждения гипотезы о строении кластера.

## Краткое резюме

Репозиторий организован вокруг двух главных направлений:

1. `paper/` — основной текст диплома и графический материал для научной работы.
2. `presentation/` — слайды и заметки для публичной защиты.

Дополнительно в корневой папке находятся служебные документы по научному руководству, рецензированию и организации защиты. В такой структуре репозиторий удобно использовать как архив научной публикации, её визуализации и сопровождающей презентации.
